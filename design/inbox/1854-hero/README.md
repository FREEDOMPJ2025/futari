## 改了什麼

- **去掉白框和圓角**：原圖內容的範圍是 x 50–1325、y 30–741，圓角半徑約 60。兩張都只取圓角以內的部分，四個角沒有白色。圓角交給版面處理，現在已經是 `rounded-3xl overflow-hidden`。
- **拿掉右下角的星形浮水印**：原圖約 (1295–1325, 690–725) 有一個灰色四角星，兩張的裁切都避開了它。
- **桌面版**：取 x 108–1278、y 100–720。上方的光帶切掉 70px，人物在畫面中的比例變大。水平中心對準兩人手上的手機（x 693）。
- **手機版**：取 x 240–1142、y 140–720，比例 1.555，跟帶狀區 392×252（1.556）一樣，所以 `object-cover` 不會再裁掉兩側。檯燈、彩帶、兩人和手機都在畫面裡，人物比原本大約 1.5 倍。

## 為什麼手機版不是直式

#1848 原本寫「手機版另裁一張直式」。看過程式後，我改成跟帶狀區同比例的特寫，原因有兩個：

1. 手機的插畫位置是固定的 392×252 橫向帶狀區（`IllustrationSlot.tsx`：`h-[252px]`）。直式圖放進去，會被 `object-cover` 切回橫的；要改成直式就得把帶狀區拉高，CTA 會被推到第一屏下面。
2. 原圖高度只有 712px 可用，裁成 4:5 直式只剩約 460px 寬，在 392px 寬、DPR 3 的手機上會糊。

如果之後真的要改成直式版面，需要重新出圖（畫高一點的原稿），不能只靠裁切。

## 套用時要注意（給實作的人）

- 手機版要用新檔名 `illustration-hero-mobile.png`：`IllustrationSlot` 的 mobile 分支（`getImageProps` 的 `src`，preload 和 `<source>` 也用同一個呼叫產生）改指向它；桌面分支和 `sign-in/BlogSection.tsx` 繼續用 `illustration-hero.png`。
- `object-top` 可以留著。新的手機圖跟帶狀區同比例，實際上不會再被裁。
- **光點起點**：`.lp-dot-band-*` 的起點是 (50%, 68%)。新圖裡手機的位置是：手機版 (50.2%, 69.0%)，桌面版 (50.0%, 71.0%)（`object-center`，欄位比例不同時只裁上下或左右，中心不變）。不用改 CSS，但套用後請在 390 和 1024 兩種寬度看一下，確認光點是從手機冒出來的。
- 照 `IllustrationSlot.tsx` 開頭的註解，在 390 和 1440 兩種寬度檢查 network：每種寬度都只下載一張圖。
- 這個 PR 只交素材，不改程式；套用請另開 PR。
