# 順心堂——Futari 加入堂口

## 這是什麼

Futari 加入有種智慧實驗室的「順心堂系列」。這個系列的設定是：順心堂是三兄弟（阿正、角頭、阿和）開的堂口，專門陪人處理生活裡卡住的事，每個 App 是堂口開的一攤新生意。Futari 是其中一攤：陪兩個人一起把家裡的帳記下來、分清楚、回頭看。

系列的世界觀、主視覺、UX 慣例與文案原則由 kit 定義，原稿收在 [`docs/design/shunxintang-kit/`](../../design/shunxintang-kit/README.md)。kit 是 SwiftUI 寫的；Futari 是 web＋Capacitor 薄殼，所以這份 spec 定的是「採用什麼、哪裡跟 kit 不同」，不是移植 kit 的程式碼。

## 為什麼

- 擁有者 2026-10-12 決定把 Futari 收進同一個系列（v2.0.0，tracker #1657）。同一個出品方的作品要讓人一眼認得出是同一家。
- 系列的產品立場跟 Futari 本來就一致：不給壓力、不倒數、不扣分、沒有連續紀錄懲罰、隨時可以離開。這跟 [PRODUCT.md](../../../PRODUCT.md) 的「不評判」「陪伴」、anti-reference「gamified guilt」是同一件事，換的是外觀與聲音，不是立場。

## 給誰

- 現有的兩人帳本使用者：功能與資料不變，外觀、導覽和語氣改變。
- 第一次看到 Futari 的人：從 landing 和商店頁就認得出這是順心堂的作品。

## 從 kit 帶過來的

**世界觀與角色**：三兄弟的名字、造型、顏色固定（阿正＝番茄橘方塊、角頭＝鈷藍三角一字瞇眼、阿和＝芥末黃星芒）；一起出場時角頭在左、阿和在中間（較小、略高）、阿正在右。擔當與台詞可以依 Futari 調整。

**主視覺**：剪紙拼貼＋蠟筆紋理。所有形狀都是手剪紙片（不是圓角）；角色有斜向蠟筆筆觸，線條會輕微抖動。扁平，卡片是紙色＋一圈淡墨線，沒有錯位陰影。淺色、深色各一套獨立色票。系統字，不用圓體，標題粗。

**UX 慣例**：開場（三兄弟彈出、跳一下）、首次介紹（三兄弟各一頁，可略過、可重看）、單一頁面堆疊不用底部分頁、左上選單（外觀、音效、重看介紹、關於）、主要動作在右上、輸入用 sheet、儀式與慶祝全螢幕、關於頁有一條「堂規」、外觀可選跟隨系統／淺色／深色、音效可關。

**版面與文案原則**：一個畫面最多三個閱讀重點；不給壓力；台灣口語（避免「下午好」「視頻」「質量」）；溫馨、帶一點點台式幹話；操作指示一個動作，不讓使用者再做選擇。

## Futari 跟 kit 不同的地方

| 面向 | kit | Futari | 原因 |
|---|---|---|---|
| 平台 | SwiftUI、iPhone 直式 | web＋iOS／Android 薄殼，手機與桌面 | 平台差異只能 runtime 判斷（CLAUDE.md「三平台架構」） |
| 語言 | 繁體中文（台灣） | 四語：zh-TW 主稿，zh-CN、en、ja 跟進 | [locale-currency](locale-currency-design.md) |
| 錢 | 沒有收支概念 | 收入、支出、欠款、餘額要能一眼分辨 | kit「不用警告紅」照守；收支用什麼顏色見 #1658 |
| 分類與愛物色 | 5 個角色色 | 10 個分類色＋7 個愛物色 | 怎麼對應見 #1658 |
| 資料 | 只存在手機裡 | 雲端同步、兩人即時共用 | 產品本質不同；「資料只在手機」這條不適用 |
| 幹話的分寸 | 對象是一個人的生活小事 | 對象是兩個人的錢 | 欠款、刪除、離開帳本這類時刻不開玩笑（範圍見 #1658） |

## 還沒拍板（#1658）

這一攤在做什麼的一句話、三兄弟的擔當與台詞、堂規、收支配色、分類與愛物色、字體（Android／Windows 沒有蘋方）、深色模式範圍、四語口吻與三兄弟名字的寫法、幹話的分寸、App 圖示主體、音效與觸覺要不要做。拍板後寫回上面的 Locked decisions。

擔當草案（待拍板）：阿正＝記帳衝鋒（隨手記一筆）、角頭＝把關（對帳、結算、守保單）、阿和＝和事佬（兩人分攤、結算時講好聽話）。

## 不做

- 改名、改網域、改商店名稱
- 改功能或資料模型：這版只換外觀、導覽、語氣
- 照搬 kit 的 SwiftUI 程式碼；也不在 web 上模擬 iOS 系統音效與觸覺的行為細節

## 完成的樣子

- App 內與品牌頁都是順心堂視覺，淺色、深色都過 WCAG AA；任何畫面都看不到提燈時期的圓角與陶土紅；字體照 #1658 的決定
- 三兄弟出現在開場、首次介紹、關於頁與情感節點（空狀態、第一次記帳、結算、月回顧）；開了「減少動態」時不抖不跳
- 導覽是單一頁面堆疊＋左上選單；「記一筆」的步數不比改版前多
- 四語文案都是順心堂口吻，經過 needs-copy 審閱
- iOS／Android 圖示、啟動畫面、商店素材都換新並已上架；關於頁、landing 掛「順心堂出品」
